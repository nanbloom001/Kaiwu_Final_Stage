## 1. 本阶段只解决一个问题

把原始复赛 Standard 10288 的动作行为迁移到可拆分感知模块的网络：

```text
源教师 T0：
  [proprio45 | height_scan256] = 301
  → 512 → 256 → 128 → action12

目标学生 T1：
  height_scan256 → 512 → 256 → latent32(L2Norm)
  [proprio45 | latent32] = 77
  → 512 → 256 → 128 → action12
```

本阶段不使用深度图、不训练视觉 LSTM、不使用 Goal、不扩展命令能力、不通过 reward 学习新行为。

原始 checkpoint 的真实张量已经核对：Actor 第一层 `[512,301]`、Critic 第一层
`[512,316]`、Actor 输出 `[12,128]`，且不存在 `encoder.*`。这不是根据文件名或
平台模型 ID 推断，而是对 SHA 锁定文件的结构审计。

网络结构只在训练开始时切换一次。训练稳定性来自驱动比例和数据难度的分步推进，而不是连续创建多个不同层数的中间网络。

## 2. 旧 `hjcnew蒸馏1_10288` 的实际路线

旧实现采用正确的总体桥接方向：

- `Config.CURRENT = StandardRefDistillConfig`；
- frozen flat `ActorCritic` 作为教师；
- `ActorCriticEncoder` 作为学生；
- loss 只有 deterministic action MSE；
- 输出具有 `encoder.* + actor.*`，可供 LBC 拆分。

旧配置为 1024 env、`lr=3e-4`、名义 5000 iterations、每 iteration 24 步，并从第一轮启用摩擦随机化、观测噪声和 push。它还把初始命令改为
`vx=[0.3,0.6]`、`vy=[-0.2,0.2]`、`wz=[-0.5,0.5]`，没有保持本轮已核对的
源教师范围。`student_drive=false`，环境始终由教师驱动。

旧 workflow 的关键行为：

```text
student_drive=false:
  update(student, teacher_action)
  env.step(teacher_action)

student_drive=true:
  env.step(student_action)
  only compute metrics
  no update
```

因此它不是 DAgger。打开 `student_drive` 后只评估学生，不会在学生访问状态上继续训练。

旧 checkpoint：

- 文件：`archive/代码存档/hjcnew蒸馏1_10288/ckpt/model.ckpt-locomotion-10288.pkl`；
- SHA256：`eb6da58646f7d4a437791de5ae32c6df0061c753e725f7089d233e229aa97a27`；
- 元数据 `train_time=650`，与约 10 分钟短跑一致；
- 含 `encoder/actor/critic_encoder/critic/std` state dict；
- 不含 optimizer、iteration、父 SHA 或 resume 状态；
- checkpoint 文件名和 `train_step=10288` 不能证明完成了 10288 次有效梯度更新。

来源边界：上述旧实现和旧 checkpoint 来自原主工作区的未跟踪本地快照 `archive/代码存档/hjcnew蒸馏1_10288/`，它不在本计划的 `origin/main@ba175ca` 文件树中。本文只固化已审计的行为和 checkpoint SHA，不把该未跟踪目录当作可复现代码基线。若后续要依赖其具体代码，必须先将经审查的快照单独归档，并记录 commit 与目录哈希。

结论：旧 checkpoint 是有效的管线对照和 LBC 教师候选，但未完成学生闭环验收，不能仅凭 10 分钟训练和低 action loss晋级为正式 `T1_priv_final`。

## 3. 新路线的核心判断

采用以下逻辑顺序，但在**一次 5000 iteration 平台任务**内自动推进：

```text
一次创建最终 ActorCriticEncoder
→ 2A 管线 smoke test
→ 2B 100% 教师驱动纯 BC
→ 2C 25% / 50% / 75% 学生驱动 DAgger
→ 2D 100% 学生闭环 DAgger
```

2A smoke test 与 2B 的 0% 学生驱动阶段合并在同一启动中；2C 的
25%/50%/75% 也不拆成三次付费启动。每个阶段末必须连续两个 50-iteration
窗口通过自动闸门，否则保存 `blocked` checkpoint 并正常结束。有限随机化
回放作为 R1 之后的独立轮次，不能在首轮结构迁移中自动开启。

不采用：

- 训练 10 分钟后仅凭 loss 直接进入视觉蒸馏；
- 从 0% 学生驱动一次跳到 100%；
- 学生驱动时停止反向传播；
- 在结构迁移阶段同时扩展速度、改奖励或加入新地形；
- 对 301→77 的第一层做切片、补零或无说明 partial loading；
- 把本阶段未训练的 Critic 当成可直接 PPO resume 的 Critic。

## 5. 数据与评测冻结

### 5.1 训练数据原则

- 第一轮冻结当前源快照的命令分布：`vx=[0.3,1.3]`、
  `vy=[-0.2,0.2]`、`wz=[-0.3,0.3]`，重采样间隔 `[6,10]` 秒；
- HJC 的 `vx=[0.3,0.6]`、`wz=[-0.5,0.5]` 是已经踩过的“结构迁移同时改变
  命令分布”问题，只保留为审计对照，不进入 R1；
- 两种楼梯方向都必须出现，并用实际视频而非名称判断上下楼；
- 阶段 2 不加入视觉噪声；
- 不使用 hard-start；
- 对楼梯入口、登阶中段、下降中段、急转和回零状态分别统计误差，必要时增加采样权重。

### 5.2 固定 held-out 集

训练开始前冻结一组不参与更新的数据，至少包含：

- 平地/坡地稳定行走；
- 上楼入口、前脚接触台阶、后脚登阶、楼梯出口；
- 下楼入口、前脚探步、落脚和出口；
- 直行、侧移、左右转；
- 命令阶跃和回零；
- 教师接近动作饱和与姿态恢复的困难状态。

离线指标：

- 全局 action MSE；
- 每动作维绝对 MSE；
- `MSE_i / max(Var(teacher_action_i), 1e-6)`；
- action cosine；
- P50/P95/max action error；
- 教师/学生动作幅值；
- 各地形和状态段分组指标。

闭环指标：

- 地形成功率；
- 前进距离和超时率；
- `bad_orientation`、`base_contact`；
- 摔倒率；
- 速度跟踪误差；
- 学生访问状态上的 action error。

## 6. 子阶段 2A：管线 smoke test

### 目标

证明加载、前向、梯度、保存和恢复正确。旧 10 分钟训练大致只能覆盖这一类证明。

### 配置

- 建议先用较少并行环境完成调试，通过后再扩大；
- `student_drive_probability=0.0`；
- domain randomization、观测噪声、push 全部关闭；
- 教师和学生使用相同 301 维观测；
- loss 为 action MSE；
- 不根据 reward 更新任何参数。

### 必须通过

- 教师 SHA、key、shape 严格匹配；
- action/loss/gradient 无 NaN/Inf；
- loss 在短跑中有明确下降趋势；
- 教师参数最大变化为 0；
- optimizer 参数集与 encoder+actor 完全相等；
- 保存后严格恢复，恢复前后同输入动作逐元素一致；
- 中断后 iteration/optimizer 能继续，而不是从头开始。

本阶段通过只表示训练链路可用，不表示能力迁移完成。

## 7. 子阶段 2B：教师轨迹纯行为克隆

### 目标

在教师状态分布上把新的 Encoder+Actor 动作对齐到足够准确，再允许学生驱动环境。

### 训练方式

```text
student_drive_probability = 0.0
teacher_action = T0(obs)
student_action = T1(obs)
loss = MSE(student_action, teacher_action)
env.step(teacher_action)
```

- 保持 clean 观测；
- 不扩展命令范围；
- 不改变地形定义；
- 定期在 held-out 集评估，而不是用训练窗口 loss 代替泛化指标；
- 训练预算由指标平台期决定，不由固定墙钟时间决定。

### 晋级门槛

- held-out action cosine `≥ 0.98`；
- 归一化平均 MSE `≤ 0.10`；
- 每个关键地形状态段无明显异常长尾；
- 指标连续两个评估窗口稳定；
- 教师驱动轨迹上的学生动作无饱和、NaN 或关节单维持续偏差。

若 0% 阶段结束仍未达到门槛，当前任务以 blocked 状态结束；后续恢复实验只能
继续 2B，不得因为训练任务即将结束而提前提高学生驱动比例。

## 8. 子阶段 2C：25%/50%/75% 混合驱动 DAgger

### 目标

逐步暴露学生自身造成的状态分布偏移，同时在这些状态上继续获得教师动作标签。

### 每步逻辑

```text
teacher_action = T0(obs)
student_action = T1(obs)
update T1 using teacher_action

drive_mask[e] ~ Bernoulli(student_drive_probability)
env_action[e] = student_action[e] if drive_mask[e] else teacher_action[e]
```

### 推进顺序

每一级是同一个任务内独立、可恢复且带闸门的逻辑子阶段：

1. `student_drive_probability=0.25`；
2. `student_drive_probability=0.50`；
3. `student_drive_probability=0.75`。

在线进入下一级前，两个连续 50-iteration 窗口必须同时通过第 12 节的 action、
非有限值、接管和硬终止闸门。平台训练流没有可靠的分地形完成率输入，因此
上下楼成功率、相对教师能力和视频不能伪装成在线自动闸门；它们在阶段 checkpoint
和最终 100% 学生 checkpoint 上由固定外部评测单独验收。

若某一级失败，当前任务保存 `training_status="blocked"` 后停止；blocked checkpoint
不能自动恢复到下一比例。经人工审查后才允许从前一级最佳 checkpoint 启动独立恢复实验，
增加对应困难状态采样或继续监督训练；不通过提高学习率或同时修改多个变量强行越级。

## 9. 子阶段 2D：100% 学生闭环 DAgger

### 目标

证明 `T1` 可以独立驱动环境，并能在自己访问的状态上继续获得教师纠偏。

### 训练方式

```text
student_drive_probability = 1.0
env.step(student_action)
teacher 仍对当前 obs 提供监督 action
student 仍然每步 update
```

### 最终放行门槛

- 综合闭环成功率达到 `T0` 的至少 95%；
- 上楼、下楼相对 `T0` 各自下降不超过 5 个百分点；
- 摔倒率相对 `T0` 增加不超过 1 个百分点；
- held-out action cosine `≥0.98`；
- 归一化平均 MSE `≤0.10`；
- 无持续误差积累、动作饱和或进入教师训练中未出现的异常姿态；
- 至少 3 个固定 seed 结论一致。

监督 loss 很低但闭环失败，说明是 covariate shift 或困难状态覆盖不足，不得用更长 teacher-drive 训练掩盖。

## 10. R1 后续轮次：有限随机化回放与冻结

### 目标

验证结构迁移在原教师已具备的动力学扰动范围内仍然成立，不学习超出教师的新能力。

### 启用顺序

1. 摩擦随机化；
2. proprio 观测噪声；
3. 初始姿态小扰动；
4. 最后才考虑低强度 push。

一次只开启一类随机化，并保留对应 clean 对照。深度空洞、旧帧、模糊和相机位姿扰动不属于本阶段，留给视觉蒸馏。

### 冻结条件

- clean 门槛继续满足；
- 随机化集相对 clean 的成功率下降在预先规定范围内；
- 教师和学生在相同扰动下的相对差距不扩大；
- 形成唯一 `T1_priv_bc` checkpoint 和 LBC side artifact；
- 记录其不是 PPO-ready：`critic_trained=false`。

## 12. DAgger 样本与安全契约

每一步固定为：先在当前 observation 上计算教师/学生动作和逐环境误差，再抽取
driver mask 与安全接管，执行 `env.step`，最后依据同一环境索引的终止结果进行
加权更新。权重为：

- `1.0`：正常且命令域内；
- `0.25`：教师安全接管；
- `0`：学生 NaN/Inf 或本步发生非 timeout 硬终止。

学生动作非有限时无条件由教师接管。动作差异阈值在 0% 阶段结束后固定为
`max(0.25, 2 × P95_action_L2)`。配置或观测命令越出冻结范围时直接失败，不让
教师为未知命令提供标签。正常的学生偏离和临近失败状态不被过滤。

在线闸门要求两个连续 50-iteration 窗口同时满足：action cosine `≥0.98`、
normalized MSE `≤0.10`、NaN/Inf 和教师 OOD 为 0、安全接管率 `≤10%`，以及
硬终止率相对上一阶段增加不超过 1 个百分点。它是自动调度保护，不是固定
held-out 集上的最终能力证明。

## 13. 失败诊断与回滚

| 现象 | 优先解释 | 动作 |
|---|---|---|
| loss 不下降 | 教师加载/观测顺序/梯度/学习率问题 | 停止，检查 contract，不启动闭环 |
| teacher-drive 指标好，25% 学生驱动崩溃 | covariate shift | 回 2B，加入失败状态，降低驱动比例 |
| 平地好、上楼差 | 楼梯关键状态样本被平均指标掩盖 | 分段统计并增加入口/中段采样 |
| action cosine 高但闭环差 | 小的系统性动作偏差累积 | 看逐关节 bias/P95，增加闭环 DAgger |
| 学生比教师在同一状态更差 | 结构迁移问题 | 回阶段 2，不进入视觉蒸馏 |
| 教师和学生同样失败 | 源能力缺陷 | 记录为后续视觉 RL 目标，不修改 T0 |
| 随机化开启后同时退化 | 随机化范围或分布变化 | 回 clean 最佳点，逐项缩小范围 |
| resume 后行为突变 | optimizer/iteration/config 未恢复 | checkpoint round-trip 失败，停止长跑 |

两轮有边界实验后，100% 学生闭环仍低于教师 90%，启动独立备选评估：

1. 直接用 flat 教师动作监督视觉策略；或
2. 从头 PPO 训练新的特权 `ActorCriticEncoder`，10288 只作动作正则。

备选路线必须单独编号，不能通过修改本计划的通过标准伪装成阶段 2 成功。

## 14. 旧 10 分钟 checkpoint 的使用方式

将旧模型标记为 `T1_old_10min`，只做以下工作：

- 与 `T0` 在相同 held-out 观测上比较 action；
- 分别执行 teacher-drive 和 100% student-drive 闭环评估；
- 检查上下楼、坡地和摔倒率；
- 作为新阶段 2 结果的速度/质量对照；
- 若通过全部门槛，可作为并行视觉蒸馏对照，但仍不作为新训练的 resume 父模型。

不直接续训的原因：缺少 optimizer、iteration、训练比例、父 SHA 和完整恢复契约。若强行权重续训，只能明确标记为 weight-only warm start，不得声称精确恢复旧训练。

## 16. 计划变更规则

以下变化需要升级本文版本号并写明证据：

- 改变目标网络结构或 latent 维度；
- 跳过任一驱动比例；
- 将 reward/PPO 引入本阶段；
- 更换源教师；
- 改变阶段退出门槛；
- 把 Critic 声明为已训练；
- 改变 checkpoint format。

学习率、训练预算、环境数和采样比例可以在同一版本内做单变量消融，但必须留下实验记录，且不得同时改变多个变量后得出因果结论。
