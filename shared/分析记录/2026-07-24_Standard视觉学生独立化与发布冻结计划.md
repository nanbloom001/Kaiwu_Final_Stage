## 1. 阶段判断

阶段 4 的 10 小时视觉蒸馏已经完成。最终模型达到 100% 视觉学生驱动，平台
评估和人工视频检查表明其平地、坡地、上楼和下楼能力与特权教师大体相同。
因此，`visionfull-28401` 可以冻结为第一个 Standard 视觉基线
`S0_visual_lbc`。

该结论只说明“视觉迁移没有明显损失教师已有能力”，不自动证明：

- 零速、低速、转向和速度指令跟踪已经满足高层控制要求；
- 模型已经通过深度常量/错配消融；
- 模型已经完成 Sim-to-Real 深度扰动与真实 D435i 日志验证；
- 当前 `kaiwu_train_v1` 训练包已经可以交给 Standard ONNX 导出器；
- 模型已经具备真机发布资格。

阶段 5 的目标不是无条件启动 PPO，而是先冻结可回滚基线，再根据可复现缺陷
决定是否进行受约束视觉学生 RL。

## 2. 阶段 5 的唯一目标

形成一个不依赖教师和 `height_scan` 推理、具有版本化 command 包络、能够导出
并进入真机分级验证的 Standard 视觉低层策略：

```text
depth[180,320,1] + proprio45(command 位于 [6:9]) + recurrent_state
    → VisionEncoder(CNN + LSTM)
    → latent32
    → Actor77
    → joint_action12
```

本阶段不训练 Goal/UWB、不训练 Track 高层导航、不训练迷宫策略。高层只能在
低层 command 包络和发布制品冻结后启动。

## 5. 子阶段 5B：先测 command 包络，再决定是否 PPO

视觉学生与教师地形能力相当，并不等于低层已经适合作为高层执行器。首先使用
同一 `S0` 做固定命令网格，不修改模型：

```text
vx = 0.00 / 0.10 / 0.15 / 0.30 / 0.50 / 0.70
vy = 0.00 / ±0.10 / ±0.20
wz = 0.00 / ±0.15 / ±0.30
```

每类命令至少覆盖：

- 平地 hold；
- command step；
- 低速转向；
- 前进中转向；
- 回零和停止；
- 固定 command 上下坡、上下楼。

首轮判定标准：

- 零速命令后 1.5 秒，平面速度 `≤0.05～0.08 m/s`；
- `MAE(vx) ≤0.10 m/s`；
- `MAE(vy) ≤0.08 m/s`；
- `MAE(wz) ≤0.15 rad/s`；
- 命令阶跃后没有持续过冲或振荡；
- 平地/坡地成功率 `≥95%`；
- 上楼/下楼成功率分别 `≥90%`；
- 固定集摔倒率 `≤1%`。

决策：

- 如果 S0 已满足 command 包络，跳过视觉 PPO，直接进入部署打包和低层冻结；
- 如果存在明确、可复现的停止/低速/转向/跟踪缺陷，才进入 5D；
- 不能仅凭“可能还会提升”启动 PPO。

## 7. 子阶段 5D：实现受约束 recurrent visual PPO

只有 5B 证明存在明确缺陷时执行。

### 7.1 初始化

- VisionEncoder 从 `S0_visual_lbc` 严格恢复；
- Actor77 从 `S0_visual_lbc` 严格恢复；
- Critic 重新初始化；
- 动作分布使用较小初始标准差；
- Actor 只读取 `depth + proprio45 + command + recurrent_state`；
- Critic 可以读取 `height_scan`、真实速度和其他训练期特权状态；
- optimizer 不得包含冻结教师参数。

### 7.2 训练包

继续使用：

```text
format = "kaiwu_train_v1"
schema_version = 1
stage_type = "standard_visual_ppo"
```

在现有模块上增加：

```text
modules.vision_encoder
modules.low_level.actor_state_dict
modules.critic.state_dict
modules.action_distribution
optimizers.visual_ppo
training_state.current_iteration
training_state.elapsed_training_hours / phase_label
training_state.anchor_weight
training_state.rng_state
lstm_reset_contract
lineage.s0_checkpoint_sha256
capabilities.deployable = false
```

不得复用历史失败路线的 `format="visual_ppo"`；本阶段训练恢复包只扩展当前
`kaiwu_train_v1`，部署时再生成独立 `lbc_loco` 制品。
三组学习率在首轮固定，不使用额外 LR scheduler；阶段恢复依赖 optimizer state
与墙钟进度，而不是一个不存在的 scheduler state。

### 7.3 损失与防遗忘

```text
L_total =
    L_PPO
    + λ_action * SmoothL1(current_action, frozen_S0_action)
    + λ_latent * SmoothL1(current_latent, frozen_S0_latent)
```

- 冻结 S0 只提供动作/latent 锚定，不驱动环境；
- `λ_action` 和 `λ_latent` 逐步退火；
- 第一轮不允许两者同时突然降为 0；
- 每次保存同时记录与 S0 的动作差异、地形成功率和摔倒率；
- 出现非有限权重、Critic 发散或核心地形明显退化时停止更新并保存诊断包。

### 7.4 参数来源与首轮固定边界

本阶段不从 D4/D5 继承任何正向参数。参数来源固定为：

- 模型权重和视觉观测契约：`S0_visual_lbc`；
- 地形比例：S0 的坡/反坡/上楼/下楼 `20/20/20/40%`，maze 0；
- PPO 算法默认边界：当前 Standard locomotion 主线；
- reward：继承当前 Standard locomotion 的速度跟踪和稳定性项，但关闭额外
  `forward_velocity` 正奖励，避免再次鼓励无视命令的高速通过；
- 复赛 10288 归档只证明模型血缘；其缺失的原始学习率、奖励和地形超参标记为
  未知，不得推断后写入本阶段。

首轮固定：

```text
num_envs = 128
num_steps_per_env = 48
tbptt_sequence_length = 16
actor_learning_rate = 3e-5
lstm_learning_rate = 3e-5
critic_learning_rate = 3e-4
num_learning_epochs = 5
num_mini_batches = 4
domain_rand = false
observation_noise = false
depth_augmentation = false
push_robots = false
```

CNN 全程冻结；第一轮不因为 3 小时时间较短而提高 Actor 学习率。

### 7.5 单次三小时合并训练

不再单独启动 smoke 任务，也不再安排 8～10 小时长训。平台只启动一次 3 小时
任务，加载检查、Critic 预热和 Actor/LSTM 微调在同一任务内自动切换：

| 时间 | 可训练模块 | 锚定 | 主要目的 |
|---|---|---|---|
| 0–30 min | Critic | S0 Actor 原样冻结 | 完成管线 smoke、recurrent rollout 检查和价值函数预热 |
| 30–90 min | Critic + Actor | `λ_action: 1.0→0.5` | 学习停止、低速、command step/hold/回零 |
| 90–180 min | Critic + Actor + LSTM/output head | `λ_action: 0.5→0.2`，latent 小权重保持 | 学习转向、侧移和组合 command；CNN 继续冻结 |

命令采样使用显式 bucket，而不是一个连续大范围均匀采样：

| Bucket | 比例 | 内容 |
|---|---|---|
| zero/return | 25% | 精确零速、运动后回零 |
| low forward | 25% | `vx=0.10～0.30` |
| normal forward | 25% | `vx=0.30～0.70` |
| forward + yaw | 15% | `wz=±0.15～0.30` |
| lateral | 10% | `vy=±0.10～0.20` |

command hold 为 3～6 秒，并显式生成 step-to-zero。高层将来的输出范围不得在
本轮训练前先行扩大。

前 30 分钟即为同一任务内 smoke。正确加载 S0、初始动作一致、Critic/梯度有限、
hidden/mask/sequence 正确且 checkpoint 可恢复后，才自动解冻 Actor。失败时保存
诊断包并结束，不继续消耗剩余时长。

训练期间若 rolling hard-termination 相对 S0 增加超过 2 个百分点，或 normalized
action MSE 超过 0.05，则暂停 Actor/LSTM 更新，只保留 Critic 更新并保存诊断
checkpoint，不自动进入下一解冻阶段。

每约 10 分钟按墙钟请求一次平台保存，阶段标签使用纯小写英文：

```text
model.ckpt-rlcritic-<平台ID>.pkl
model.ckpt-rlactor-<平台ID>.pkl
model.ckpt-rlfull-<平台ID>.pkl
```

平台任务页控制实际 3 小时时长；代码中的 iteration 只作为保险上限。任务完成后
统一执行 S0/S1 固定评估。只有出现“稳定改善但尚未收敛”时，才允许从最佳 S1
再续训一次不超过 3 小时，不预设第二次长训。

当前代码已经实现该时间表，但还没有平台启动证据。第一次启动应被视为
“同任务内 smoke + 训练”：若预加载、rollout、首轮 backward、命令实际值或
`rlcritic` 保存任一失败，应停止并修复，不得因为任务时长配置为 3 小时而继续
消耗整段配额。

## 8. 子阶段 5E：S0 与 S1 同集比较

若进行了 PPO，候选称为 `S1_visual_rl`。必须与冻结 S0 使用完全相同的：

- checkpoint loader；
- 评估 TOML；
- 地形、难度、命令、seed 和 episode 时长；
- 相机外参和深度预处理；
- 视频与失败类型统计。

放行标准：

- 至少一项预先声明的目标指标相对 S0 改善；
- 任一核心地形成功率下降不超过 2 个百分点；
- 摔倒率增加不超过 0.5 个百分点；
- 没有通过降低速度、拒绝登阶或僵硬小步换取分数；
- 空白/常量/错配深度显著破坏复杂地形表现；
- 深度扰动集相对 clean 下降不超过 10 个百分点；
- LSTM reset、长序列和重复推理确定性通过。

未通过时，正式发布候选立即回滚到 `S0_visual_lbc`。不得因为投入了长训成本而
降低门槛。

## 9. 子阶段 5F：低层冻结与真机分级

无论最终选择 S0 或 S1，都必须：

1. 形成版本化 command 包络；
2. 完成真实 D435i 深度日志离线回放；
3. 吊起/支架零命令；
4. 平地 `0.10～0.15 m/s`；
5. 平地低速转向和回零；
6. 逐步增加到训练覆盖速度；
7. 缓坡；
8. 低台阶；
9. 正式楼梯。

每级保留人工急停、深度 stale watchdog、姿态/关节/动作限制。低风险验证没有
通过时，不得直接用更高速度“冲过”问题。

退出标准：

- 低层 checkpoint、部署包、ONNX、配置和二进制 SHA 固定；
- 真机能稳定执行零速、前进、侧移和转向；
- 低风险地形无不可解释摔倒；
- ONNX 多帧输出与 Python 一致；
- 后续高层训练默认冻结全部低层参数。

## 10. 高层启动门槛

只有阶段 5F 完成后，才启动高层：

```text
depth + UWB Goal + memory
    → high-level navigation
    → bounded command3
    → frozen Standard visual locomotion
    → action12
```

高层 command 必须通过连续映射限制在阶段 5F 冻结的包络内。现有 Track 教师
不作为默认动作教师；其仿真过拟合、停止和转向缺陷只能作对照证据，不能重新
污染已冻结的 Standard 低层。
