## 1. 计划目标与边界

本计划只解决低层 Standard 视觉运控：训练一个最终仅依赖深度相机、`proprio45`、速度指令和循环状态的策略，使其具备平地、坡地、上下楼、转向、停车和速度跟踪能力。

本计划暂不训练高层 Track 导航、UWB Goal、避障和迷宫策略。高层只能在低层 Standard 视觉模型完成并冻结命令包络后启动。

最终期望数据流：

```text
depth[180,320,1] + proprio45(command 位于 [6:9]) + loco_state
    → VisionEncoder(CNN + LSTM)
    → latent32
    → Actor77
    → joint_action12
```

## 2. 已冻结的路线决策

以下决定是本计划的稳定边界，不能因一次短跑结果而静默改变：

1. 原始复赛 10288 永久冻结，不再在其 301 维扁平网络上继续 PPO；它只作为源教师和能力基准。
2. 阶段 1 的源教师评估与阶段 2 的结构蒸馏可以并行，但二者必须锁定同一 checkpoint SHA 和同一评测协议。
3. 先把扁平 10288 蒸馏成带 `latent32` 的特权教师，再把 height scan 感知迁移到深度视觉学生。
4. 网络结构在阶段 2 开始时一次切换到最终 `ActorCriticEncoder`；训练通过教师驱动、混合驱动和学生闭环逐步推进，不引入多个临时网络结构。
5. 阶段 2 只负责保留能力，不负责扩展速度或学习新地形。
6. 默认不对特权教师做 PPO 后训练。若源教师和结构教师都存在同一能力缺陷，优先在完成视觉蒸馏后对视觉学生做受约束 PPO。
7. 阶段 4 必须先冻结一个可部署的 `lbc_loco` 基线，再考虑 `visual_ppo`；PPO 失败时始终能够回滚到该基线。
8. 每个阶段未达到退出标准的 checkpoint 不得成为下一阶段默认父模型。
9. 原始 checkpoint 已按真实 pickle 张量审计：Actor 第一层为
   `[512,301]`、Critic 第一层为 `[512,316]`、Actor 输出为 12 维，且不含
   `encoder.*`。旧 HJC 文件中的 Actor77 是一次约 10 分钟桥接训练的产物，
   不能倒推原始 10288 已经模块化。

## 5. 阶段 1：冻结并评估原始 10288

### 目标

不修改模型，建立所有后续相对指标的唯一父基线。阶段 1 可以与阶段 2 的第一轮训练并行，但评估完成前不得宣布阶段 2 已通过。

### 必做检查

- 严格加载 `T0_flat_10288`，禁止 partial loading；
- 记录所有 state-dict key、Actor/Critic 第一层 shape 和 checkpoint SHA；
- 用实际视频确认 `pyramid_stairs` 与 `pyramid_stairs_inv` 分别对应上楼还是下楼；
- 固定 clean 评测集：平地、上下坡、上下楼、不同入口角度；
- 固定命令网格：`vx=0/0.15/0.30/0.50/0.70`，左右转、侧移、阶跃和回零；
- 至少 3 个固定 seed，分别记录成功、超时、`bad_orientation`、`base_contact`；
- 保存速度误差、机体姿态、动作和视频，而不是只保存总分。

### 退出标准

- checkpoint 严格加载且观测/动作维度完全匹配；
- 上下楼、坡地能力有独立指标和视频；
- 命令响应区间和明显死区已经记录；
- 评测脚本、seed、地形方向和指标定义被冻结；
- 形成 `T0` 基线报告，允许与阶段 2 使用同集对比。

阶段 1 发现能力不足不触发原始 10288 续训，只影响后续教师/学生能力差距的解释。

## 6. 阶段 2：扁平 10288 → latent32 特权教师

### 目标

只迁移网络结构：

```text
T0: [proprio45 | scan256] → Flat Actor301 → action12

T1: scan256 → Encoder → latent32
    [proprio45 | latent32] → Actor77 → action12
```

`latent32` 没有外部真值标签，由教师动作监督和学生闭环状态上的 DAgger 间接形成。

### 实施原则

- 教师冻结并在训练前后校验参数 hash；
- 第一轮关闭新增随机化、观测噪声和 push；
- 命令只覆盖阶段 1 证明教师有效的范围，不在结构迁移中扩展能力；
- 先 100% 教师驱动行为克隆，再按环境独立提高学生驱动比例；
- 无论谁驱动环境，都在当前状态上查询教师动作并更新学生；
- optimizer 只包含学生 Encoder 和 Actor；Critic/探索标准差不作为本阶段产物能力的一部分；
- 每个子阶段均可恢复、可回滚，禁止只保存裸 state dict。

当前第一轮固定为 `STD-BRIDGE-R1`，在**一次 5000 iteration 启动**内自动完成：

| iteration | 学生驱动概率 |
|---:|---:|
| 0--1499 | 0% |
| 1500--2249 | 25% |
| 2250--2999 | 50% |
| 3000--3749 | 75% |
| 3750--4999 | 100% |

每个阶段末用两个连续 50-iteration 在线窗口生成质量诊断。阈值超限只
记录 warning 和 checkpoint 状态，训练仍按预定 DAgger 比例继续；固定评测集上的
外部闭环验收才决定是否晋级下一总阶段。

R1 使用源教师命令包络 `vx=[0.3,1.3]`、`vy=[-0.2,0.2]`、
`wz=[-0.3,0.3]`，坡/反坡/楼梯/反楼梯比例为 `20/20/20/40%`，迷宫为 0。
为了隔离结构迁移，首轮关闭动力学随机化、观测噪声和外力推动；奖励表仅用于
保持环境定义与源快照一致，R1 不进行 reward/PPO 更新。

详细子阶段、指标和 checkpoint 契约见配套执行计划。

### 退出标准

- held-out `action_cosine ≥ 0.98`；
- 按动作维归一化后的平均 MSE `≤ 0.10`，并报告近常量维绝对 MSE；
- 最终 100% 学生驱动；
- 闭环综合成功率达到 `T0` 的至少 95%；
- 上楼、下楼单项相对 `T0` 下降不超过 5 个百分点；
- 摔倒率相对 `T0` 增加不超过 1 个百分点；
- 教师参数训练前后逐字节一致；
- 输出 `privileged_loco_teacher_v1` side artifact，且能被 LBC teacher loader
  严格加载；历史 raw `encoder.* + actor.*` 仅保留兼容读取。

若两轮有边界实验后仍低于教师能力的 90%，停止继续延长训练，转入结构瓶颈或直接视觉动作蒸馏的独立对照，不降低验收门槛掩盖失败。

## 7. 阶段 3：特权教师验收、命令包络与冻结

### 默认路线

默认不做特权 PPO。用阶段 1 的同一评测集对比 `T0` 和 `T1_priv_bc`，得到唯一 `T1_priv_final`：

- 能力相同处记录保留程度；
- 两者共同缺失的能力标记为后续视觉学生 RL 目标；
- 仅 `T1` 新出现的缺陷视为结构蒸馏失败，回到阶段 2；
- 固定后续视觉蒸馏允许使用的命令包络；
- 固定唯一 checkpoint、配置、commit 和 SHA256。

### 特权 PPO 的触发条件

仅满足以下任一条件时才考虑：

- 视觉学生 PPO 多次在同一关键能力上崩溃；
- 需要先在理想 height scan 下验证某项奖励或课程是否可学；
- 教师缺失的是比赛必需能力，且直接视觉探索成本不可接受。

若执行特权 PPO：Critic 必须重新初始化并预热；Actor 初期使用冻结 `T1_priv_bc` 动作锚定；每次只改变一个训练变量。教师一旦改变，阶段 4 必须从新教师重新蒸馏或完成明确的补蒸馏。

### 退出标准

- `T1_priv_final` 的能力边界和命令包络有量化报告；
- checkpoint 血缘唯一，无同 ID 异结构制品；
- 后续阶段不再静默更换教师；
- 若未做 PPO，明确标记 Critic/critic encoder/std 不属于已验证参数。

## 8. 阶段 4：特权教师 → 深度视觉 Standard

### 目标

冻结 `T1_priv_final` 的 Encoder 和 Actor，只训练视觉 Encoder：

```text
depth + proprio45 → CNN + LSTM → student_latent32
student_latent32 + proprio45 → frozen Actor77 → action12
```

### 训练顺序

1. clean 深度、教师驱动、平地和坡地；
2. clean 深度、教师驱动、上下楼，强化 raw-action 对齐；
3. 学生驱动 `25% → 50% → 75% → 100%`；
4. 扩展到阶段 3 冻结的零速、低速、转向和组合命令；
5. 依次加入摩擦随机化、proprio 噪声、深度空洞/飞点、旧帧、内外参扰动；
6. 使用真机深度日志离线回放检查分布差距。

首轮损失建议：

```text
0.5 * SmoothL1(student_latent, teacher_latent)
+ 0.1 * cosine_loss
+ 1.0 * SmoothL1(student_action, teacher_action)
```

具体权重必须根据梯度量级短跑校准，但不得在同一次实验中同时改变驱动比例、地形、命令、随机化和损失。

### 退出标准

- 最终 100% 视觉学生闭环驱动；
- clean 综合能力达到教师的 90%～95%；
- 上下楼/坡地相对教师下降不超过 10 个百分点；
- 摔倒率相对教师增加不超过 1 个百分点；
- 深度扰动集相对 clean 下降不超过 10 个百分点；
- 空白/常量深度显著破坏复杂地形表现，证明策略使用视觉；
- eval 关闭随机增强，同一输入重复推理确定；
- LSTM 在 episode reset 后可复现、长序列无 NaN/Inf；
- 生成首个可导出的 `format="lbc_loco"` checkpoint。

## 9. 阶段 5：视觉学生独立化与部署冻结

### 先冻结可部署基线

阶段 4 通过后，先冻结 `S0_visual_lbc`，完成：

- Python 多帧 recurrent 推理；
- Python 与 ONNX 多帧误差 `≤ 1e-4`；
- LSTM reset、模式切换和急停复位；
- 真机深度日志离线回放；
- 吊起零速、平地低速、转向和回零；
- 坡地、低台阶、正式楼梯逐级测试。

若 `S0` 已满足比赛需求，可以直接作为发布候选，不强制进行 PPO。

### 可选受约束视觉 PPO

只有存在明确、可复现的指标缺陷时才启动。启动前必须：

- 删除或改正使用世界坐标 `root_pos_w[:,2]` 的 `correct_base_height`；
- 保持与 `S0` 相同的地形、命令和奖励，先只改变训练算法；
- 冻结视觉 Actor，先预热新 Critic；
- 使用 `S0` 作为强动作锚点，稳定后再逐步退火；
- recurrent PPO 按序列采样，保留 done mask 和 hidden state 边界；
- 为 `format="visual_ppo"` 增加 Standard 导出与部署兼容支持。

### 退出标准

- 至少一项预先声明的目标指标相对 `S0` 改善；
- 任一核心地形成功率下降不超过 2 个百分点；
- 摔倒率增加不超过 0.5 个百分点；
- 没有通过降低速度、拒绝登阶或僵硬小步换取分数；
- ONNX、部署配置和 Python 模型契约一致；
- PPO 未通过时，正式产物回滚到 `S0_visual_lbc`。

```text

→ 少量更新 smoke test
→ 短训练
→ 固定集评估
→ 通过后长训练
```

## 11. 防止计划漂移的变更规则

### 不得静默改变

- 源教师的 301 维输入/12 维输出结构；实际 SHA 可因平台重打包变化，但必须记录用于追溯；
- 五阶段顺序；
- 阶段 2 的“先教师 BC、再 DAgger、最后学生闭环”；
- 阶段 4 的“先 clean、后随机化”；
- 视觉 PPO 不是必经阶段；
- 每阶段相对能力门槛；
- server/deploy 的输入、输出和 checkpoint 格式契约。

### 可以通过消融调整

- 学习率；
- 每个子阶段训练预算；
- 环境并行数；
- 地形采样比例；
- 命令 bucket 采样权重；
- 蒸馏损失权重；
- 随机化范围。

每次调整必须写明：原值、新值、父 checkpoint、唯一变量、假设、评估结果和是否保留。若同时改变两个以上核心变量，该实验只能标记为探索，不得作为因果结论。
