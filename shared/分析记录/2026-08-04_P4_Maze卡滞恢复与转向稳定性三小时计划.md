## 一、问题归因与本轮取舍

上一轮视频和训练数据说明：

- 多个卡滞样本停止后，前视深度仍能看到近距离墙面或柱体，不是单纯的深度完全丢失。
- 前视深度无法覆盖后腿和侧后方挂柱，仍存在部分可观测性缺口。
- SafetyHead 判断正确时 Actor 仍可能选错，说明只训练诊断 Head 不足以改变动作。
- 当前安全层主要限制 vx，可能留下较大 vy 继续斜向碰墙。
- 当前 wz slew 为 1.0/2.5 rad/s^2，建立大角速度偏慢。
- 上一轮 Actor 已使用偏高学习率，KL 和 clip fraction 偏高；新增教师损失后不应恢复上一轮攻击阶段的峰值 LR。

本轮明确不采用：

- 不把 safe3 扩成五方向 SafetyHead。
- 不引入 state-dependent 或 conditional log_std。
- 不增加额外 wz EMA 低通、两次反转确认或全局 wz 裁剪。
- 不增加脱困正奖励。
- 不增加全局 shortest-path 或 geodesic 奖励。
- 不在运行时用教师方向覆盖 Actor 动作。

## 二、Actor mean 软教师

教师只定义不可接受区域，不生成完整教师动作。Actor 进入可接受区域后，辅助损失必须严格为零。

使用 deterministic Actor mean：

~~~text
policy_mean3 = CommandMapper(tanh(actor_mean3))
~~~

该损失只更新 Actor LSTM 和 mean heads。nav_feat32 在该路径上 detach，禁止 privileged teacher 直接重塑 NavigationEncoder。

### 2.1 高置信 mask

只有以下条件同时成立才计算教师损失：

~~~text
alive
teacher/scanner valid
mapping valid
not terminal/reset
not push grace / episode grace
Goal freshness >= 0.75（仅目标相关项）
best_safe >= 0.65
best_safe - second_safe >= 0.20
~~~

每次 PPO update 有效 timestep 少于 64 时，该次教师损失为零。

### 2.2 安全方向容差

保留三个扇区：

~~~text
left   = +35 degrees
center =   0 degrees
right  = -35 degrees
~~~

只在 Actor 平移方向偏差超过 35 度时处罚：

~~~text
mean_xy_dir = normalize([mean_vx, mean_vy])
cos_error = relu(cos(35 degrees) - dot(mean_xy_dir, safe_dir))
L_direction = cos_error^2
~~~

进入 35 度容差区后 L_direction=0，不继续拉向扇区中心。

### 2.3 近墙速度容差

只在 predictive risk >=0.65 或有效卡滞状态下启用：

~~~text
u_xy = sqrt(mean_vx^2 + mean_vy^2)
u_cap = 0.20 + 0.45 * selected_safe
L_speed = relu(u_xy - u_cap)^2
~~~

该项只处罚明显过快的平移，不定义固定巡航速度。

### 2.4 目标侧向 yaw 响应

仅当目标方向与安全方向兼容时，要求正确符号的 wz：

| 目标偏角 | 最小正确符号 wz |
|---|---:|
| 0–15 度 | 0 |
| 15–35 度 | 0.06 rad/s |
| 35–60 度 | 0.12 rad/s |
| 60–90 度 | 0.18 rad/s |

~~~text
L_yaw = relu(wz_required - sign(goal_bearing) * mean_wz)^2
~~~

vy 可以辅助横移，但无法使 L_yaw 归零，因此不能完全替代机身转向。不单独处罚 vy 幅值。

### 2.5 总损失和梯度预算

~~~text
L_teacher =
    0.40 * L_direction
  + 0.35 * L_speed
  + 0.25 * L_yaw
~~~

不使用固定 loss coefficient。每次 PPO update 的首个 Actor microbatch重新计算 PPO 与辅助梯度范数。

~~~text
教师梯度目标：2.0%–2.5% PPO Actor gradient
教师梯度硬上限：3.0%
camera + teacher + mirror + stuck 总辅助梯度硬上限：5.0%
~~~

teacher target、mask 和权重必须在采样时写入 rollout，与 pre-tanh action、old log-prob、initial hidden 和 reset mask 使用同一 TBPTT16 时间轴重放。禁止 update 时根据当前 worker 状态重新生成标签。

## 三、卡滞标签与恢复窗口

将 wall-stuck reset 确认时间从 7s 延长到 10s：

~~~text
0–0.8s：普通碰撞观察期，不启用恢复教师
0.8–2.0s：高置信疑似卡滞，教师样本权重 0.25
2.0–10.0s：确认卡滞，教师样本权重 1.0
10.0s：训练标签进入 confirmed 状态；真实 reset 只有 worker 收到可信高层运动意图时才允许
~~~

疑似卡滞必须同时满足：

~~~text
root displacement 显著过小
policy/exec 存在运动意图
true motion 很低
存在墙面或非足端接触证据
mapping valid
非 episode/push grace
非 terminal/reset tick
~~~

恢复成功后立即退出恢复 mask。reset 必须计为 failure/timeout，不能进入 completion。

平台边界补充：当前没有经过验证的 aisrv 到 worker 高层运动意图 transport，原生
`base_velocity` 不能代表 P4 实际 exec command。因此本轮生产配置保持 `mode=shadow`，训练 wire
升级为 509，并输出 motion-intent hook 可用性和独立 raw wall term；缺少 hook 时 active reset
fail-closed。10 秒真实 reset
合同保留为后续能力，不伪装成本轮已经具备。

新增 training-only：

~~~text
Actor LSTM hidden -> stuck_logit
~~~

该 Head 不增加 Actor observation 维度，Track/Standard eval 可忽略。stuck 分类单独做正负样本平衡，并记录 PR-AUC 和校准阈值。

## 四、Slew 与训练型轻量消抖

不运行固定 checkpoint 行为 A/B，直接使用保守升级：

~~~text
vx increase/release = 0.30 / 0.30 m/s^2
vy increase/release = 0.40 / 0.80 m/s^2
wz increase/release = 1.50 / 3.00 rad/s^2
~~~

继续保持：

- 指令反向时先回零，禁止一步越过零点。
- 现有 1s yaw-cancellation 作为训练型消抖。
- 现有轻量 command-rate 惩罚。
- 分别记录 target-to-exec 与 exec-to-true yaw 延迟、过冲、sign flip 和 cancellation。

不增加额外 EMA、两次反转确认或全局 wz 限制。

slew 变更必须同步 command contract/digest、capability profile、predictive rollout 和 Track eval，不能只改 TOML。

## 五、平移安全 limiter

将只限制 vx 的安全层改为缩放完整平移向量。限制器只使用部署可得的 depth predictive risk，不使用 privileged safe3 或 SafetyHead 输出。

~~~text
risk = deployment-available predictive risk
alpha_raw = clamp(1 - 0.65 * risk, 0.35, 1.0)

limited_vx = alpha * policy_vx
limited_vy = alpha * policy_vy
limited_wz = policy_wz
~~~

语义：

- 风险升高时立即收紧。
- 风险解除时，alpha 每个 10Hz tick 最多增加 0.15。
- 不改变平移方向，不为 Actor 选择安全出口。
- 不压缩 wz，防止在墙前同时压制脱困转向。
- reset 后 alpha_prev=1；live limiter 状态不写入 checkpoint。

## 六、奖励预算

当前 goal-safe preference 原始上限为 -0.04，且在统一 safety group 之外。本轮将它改为轻量 tie-breaker：

~~~text
goal-safe preference raw cap = -0.012（5Hz reference）
yaw exit response raw cap    = -0.006（5Hz reference）
~~~

正常 10Hz tick 经 duration scaling 后最多约 -0.006 和 -0.003。

以下项统一纳入同一个 proportional safety group：

~~~text
predictive collision
missed safe direction
yaw cancellation
yaw exit response
goal-safe preference
~~~

安全组总预算不扩大：

~~~text
5Hz reference raw floor = -0.060
正常 10Hz tick 约不低于 -0.030
~~~

其他奖励边界：

- success 保持 +200。
- confirmed wall-stuck reset 保持 -15。
- sustained stuck 保持现有基础值和 floor；确认窗口由 7s 延长到 10s 后，其递增速度自动放缓。
- route-excess 不提高权重；recovery、dead-end、Goal stale 和接触 latch 期间暂停该项。
- 不新增 recovery bonus、持续 heading 正奖励或绝对距离正奖励。
- wall-stuck terminal tick 不重复计算 collision、predictive、stuck sustained 和 reset penalty。

## 七、近终点软捕获

不新增距离正奖励、本地 success 或提前 terminal。平台 scorer 仍是唯一成功判据。

启用条件：

~~~text
Goal freshness >= 0.90
not terminal/reset/goal epoch change
0.65m < GoalBelief distance < 1.20m
||policy_xy|| > 0.10
cos(policy_xy, goal_xy) >= 0.70
~~~

软平移上限：

~~~text
capture_cap(d) = 0.10 + 0.35 * clamp((d - 0.70) / 0.50, 0, 1)
alpha_capture = min(1, capture_cap / ||policy_xy||)
final_xy = min(alpha_safe, alpha_capture) * policy_xy
final_wz = policy_wz
~~~

同时：

- 屏蔽 soft-cruise 低速惩罚和 crawl deadzone。
- 保留正确 yaw 响应，但不修改方向。
- 不把速度强制归零，确保仍能进入平台 0.6m 成功半径。
- Goal stale 时完全禁用。
- 只记录 capture 候选、进入、离开、success、collision 和 timeout，不增加 near-goal 奖励。

## 八、左右镜像一致性

从 rollout 内任意真实 reset 起点构造初始 hidden 为零、序列内不再跨 reset 的完整 TBPTT16，
按全部 PPO sequence-update 的约 10% 调度镜像；合格 episode 较少时允许有放回重复抽样：

~~~text
depth horizontal flip
goal_y -> -goal_y
vy -> -vy
wz -> -wz
safe left/right swap
reset mask unchanged
~~~

- 只更新 Actor LSTM 和输出层。
- 镜像梯度目标约为 PPO Actor 梯度的 0.5%，硬上限 1.0%。
- 仅使用无 terminal、无 push、无 reset crossing、映射有效的序列；面板必须同时报告合格序列数、
  实际 microbatch share 和全 rollout 调度 share，避免固定 chunk 边界导致镜像名义开启但实际为零。
- 只缩小系统性左右偏置，不要求动作逐值完全对称。

## 九、Camera、SafetyHead、Adapter 与 Push

Camera 本轮不继续增加 fault/delay：

~~~text
0–90min：nominal 90%，light 10%，delayed 0%，severe 0%
90–180min：nominal 80%，light 20%，delayed 0%，severe 0%
~~~

对墙面漏检、岔路、碰撞前窗口和卡滞样本做 hard-positive replay。SafetyHead 保持三方向，不增加 Actor 输入维度。

Adapter stuck head：

- 正样本使用 mapping valid、非 push/reset 的卡滞窗口。
- stuck 分类单独做正负样本平衡，不改变 velocity/pose replay 比例。
- 记录 PR-AUC、precision、recall、校准阈值和有效样本覆盖。
- 本轮不依赖 Adapter stuck 输出直接触发恢复或 reset。

Push 本轮全程关闭，避免墙面恢复和外力恢复混在同一个三小时实验中。

## 十三、验证计划

### 本地定向测试

1. 方向偏差在 35 度内 loss 为零，超出后连续增长。
2. vy 不能使 L_yaw 归零，只有正确符号 wz 可满足。
3. 模糊岔路、dead-end、Goal stale、push、terminal、reset 和 mapping invalid 的教师 mask 全部为零。
4. 教师损失不更新 NavigationEncoder，合成辅助梯度不超过 5%。
5. label、mask、hidden 和 reset 使用同一 TBPTT 时间轴，不跨 episode。
6. 验证新 slew 的增速、释放、先归零再反向和无越零 overshoot。
7. limiter 同比例缩放 vx/vy，wz 不变，镜像后结果对称。
8. 近目标逻辑不在 0.6m 前归零，Goal stale 时禁用。
9. safety group 分解和等于 PPO storage reward，terminal 不重复处罚。
10. 双次镜像恢复原序列。
11. warm-start 时父策略在教师关闭状态下输出一致，新 Head 可保存和恢复。

### 开发容器与平台

- 开发容器仅做最小必要 smoke：1–8 环境完成一次 32-tick rollout、PPO update、Adapter update、save/resume。
- 检查 command contract、slew、teacher mask、auxiliary gradient ratio、reward conservation 和非有限值。
- 平台先运行 15–30min smoke，核对行为链、shadow 卡滞候选、motion-intent availability、近目标捕获、
  KL/clip 和模型保存。当前平台边界下 reset count 应为零，不能把它解释成卡滞检测失效。
- smoke 通过后启动完整 10,800s 任务。
