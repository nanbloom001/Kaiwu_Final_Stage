# 复赛到决赛模型迁移与蒸馏审计

本目录记录 2026-07-10 对仓库中复赛 Standard、复赛 Track、决赛原始代码和决赛 Track 视觉蒸馏存档的完整静态审计结果。

本次审计重点回答三个问题：

1. 当前已经完成了哪些训练与工程工作；
2. 复赛模型为什么不能直接加载到决赛网络；
3. 下一步需要如何完成行为迁移、视觉蒸馏和 Sim2Real 部署闭环。

## 文档

- [深度相机模型训练入门指南](./深度相机模型训练入门指南.md)：面向初学者，从 Tensor/shape、MLP、CNN、LSTM、Actor-Critic 和 PPO 开始，逐步讲解行为蒸馏、LBC、完整训练流程、checkpoint、指标、相机标定、ONNX、阅读路线和动手练习。
- [迁移路线评估与训练代码质量审查](./迁移路线评估与训练代码质量审查.md)：比较从头 PPO、warm-start、两段蒸馏、pseudo-scan、端到端动作蒸馏和隐藏层蒸馏，给出当前首选路线、代码 P0/P1/P2 缺口、决策树和放行门槛。
- [审计报告](./审计报告.md)：完整结论、架构对比、checkpoint 状态、问题清单、执行路线和验收标准。
- [证据索引](./证据索引.md)：按阶段列出支撑结论的代码、配置、规则和训练产物位置。

初次接触模型训练时，建议先读入门指南，再读审计报告；需要核实某个结论时再查证据索引。

## 一句话结论

复赛 `Standard -> Track` 不需要蒸馏；复赛 flat Track 若要迁移到决赛 `ActorCriticEncoder` 并保留既有导航能力，首选增强版“行为蒸馏 + 小学习率 PPO 修正 + LBC”，从头 Encoder PPO 作为对照和兜底。仓库已有一个约半程的视觉 checkpoint，但当前训练代码尚未接通可复现的行为蒸馏入口，Teacher 血缘、闭环性能验证和 actor80 真机部署也尚未完成。
