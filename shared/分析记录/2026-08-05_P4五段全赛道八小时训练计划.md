# P4 五段全赛道八小时训练计划

## 目标

- 任务：`p4full8h-r2`；分支：`codex/p4-full8h-r2`。
- 父包：`p4maze8h10hz_1416926`；有效训练 `28800s`。
- 在保留 Maze 完成能力的同时，补齐正坡、逆坡、正楼梯、逆楼梯和 Maze 的完整串联导航。
- 重点降低开阔地 S 型、长距离 Goal 跳变导致的摆头、墙面卡滞和单一出生点造成的局部最优。

## 训练合同

```text
128 env
10Hz high level / 50Hz low level
32 nav ticks / TBPTT16
frozen low level
120s episode
20 static columns
curriculum=false
```

赛道固定为：

```text
pyramid_slope
-> pyramid_slope_inv
-> pyramid_stairs
-> pyramid_stairs_inv
-> open_entry_maze
```

学习率阶段为 0-30m、30m-2h、2-6h、6-8h；最后两小时降低 Actor/CNN/Critic LR 和 entropy，
不做性能提前停止。

## 避免局部最优

1. 出生覆盖同时保留整轨任务和局部困难样本。整轨比例按 70% / 60% / 75% 调整，其余样本按
   15/15/20/20/30% 分配到五段，并覆盖四个段内分位。70% 使用平台安全点，30% 请求困难位置。
2. 困难位置必须经过运行时地表命中和八方向机身 clearance 校验。缺少 raycast、数据非法或写入失败
   时退回同段入口并上报，不能用 requested count 伪装成实际覆盖。
3. reason 4 前两次回到同一出生桶，第三次只退回同段入口，不允许推进到更后段，以免 reset 降低任务
   难度并抬高完成率。
4. 五段 frontier 是 terminal-clawed potential，episode 结束时回收，长期净收益为零。全局
   route-excess 关闭，避免对 Maze 必要绕行形成持续压力。
5. 开阔直行只在正/逆坡、teacher 明确中心安全、Goal 新鲜、远离段边界且非路口/死胡同/碰撞/恢复
   时生效；楼梯和 Maze 严格关闭。三项合计不低于 `-0.0125/tick`，只抑制 lateral drift、S-turn
   cancellation 和额外路程，不奖励固定速度或固定朝向。

## Goal 鲁棒性

- Goal shape 不变。10m 内保持旧 `xy/10`，10m 外改为单位方位，距离仍为 `min(d/20,1)`。
- 跳变只进入 Actor GoalBelief；Critic、reward 和 scorer 使用干净真值。
- 跳变率 `0.015/s`、持续 `0.2-0.8s`、仅在 `d>=3m`：

```text
capture = smoothstep((d-1.5)/1.5)
radial  = capture * clamp(0.04+0.004*d, 0.04, 0.20)
tangent = capture * clamp(0.10+0.05*d, 0.10, 1.00)
```

椭圆内均匀、零均值采样；近终点自然衰减，避免重复上一轮“进入不了成功半径”的问题。

## 卡滞和终止

- active reason 4 使用最近 10 秒世界坐标窗口：空间直径小于 0.50m、真实平移速度低于 0.08m/s、
  Goal 距离大于 0.8m，并存在有效非足端墙面证据。
- 不依赖命令意图，不把主动停车作为恢复证据；Push 关闭。
- success 优先级最高；reason 4 是失败边界，奖励 `-25`，不计完成，不 bootstrap，不重复结算
  collision、安全或持续卡滞惩罚。

## 验收和风险

- 本地：合同、reward、Goal、spawn、monitor、checkpoint 定向测试；编译、TOML、diff check。
- 容器：1 env 证明 raycast 随机出生和 reason 4 物理 reset；8 env 完成 32 tick PPO、Adapter、
  save/resume。无需重复 128 env 显存专项。
- 平台：先看五段真实出生、hard-position applied、reason4 physical reset、reward conservation 和
  Goal jump，再启动完整八小时。
- worker quota/RNG 没有公开 checkpoint transport。fresh-process resume 会按 seed 重新初始化该
  分布；模型、optimizer 和 learner 时钟仍可 exact resume。报告必须明确该边界。
- 最终分别报告五段完成/失败/timeout/reason4、出生段与终止段、正负 vy/wz 链路、S-turn、Goal
  clean/fault 方位、卡滞回收和 Maze 完成率，不能只看总 reward。
